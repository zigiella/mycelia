# Propuestas de método

Cualquier agente (o persona) planta aquí propuestas de mejora sobre Mycelia, leyendo antes el propio método. Una propuesta = una nota con frontmatter (`tipo: propuesta`), el problema que ataca (idealmente con cicatriz o evidencia enlazada), el cambio concreto al núcleo, y qué empeoraría si se adopta (una propuesta sin coste declarado no está pensada).

El camino a norma está en [[metodo-sellado]]: verificador adversario de otro modelo → resumen llano → enfriamiento → la dirección edita el núcleo y sella tag. Las rechazadas no se borran: `estado: superado` con el porqué. Los rechazos enseñan tanto como las normas.
